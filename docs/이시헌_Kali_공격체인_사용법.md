# Kali 5단계 공격 체인 스크립트 사용법

작성: 이시헌 · 2026-10-20 · 스크립트: `scripts/kali_breach_chain.py`

표준 라이브러리만 쓴다(설치 필요 없음, Kali의 `python3`면 된다). **읽기·게시만 하고 데이터를 지우거나 바꾸지 않는다.**

## 준비물
- 공격망(Kali)에서 포털 주소로 접속이 되는 상태(위 pfSense 규칙 적용 후).
- 이미 확보했다고 가정하는 **직원 계정**(예: `kim`) 아이디·비밀번호. 계정 탈취 자체는 이 스크립트 범위가 아니다(그건 로그인 방어 점검 쪽, 이미 10-18에 hydra로 확인함 — 무차별 대입은 막힘).

## 실행
```
python3 scripts/kali_breach_chain.py --base http://192.168.3.14:5070 --user kim --password '비밀번호' --report 결과.md
```

## 무엇을 보여주는가
1~5단계를 차례로 보내고 각 단계를 **OK / BLOCKED / FAIL**로 표시한다.

- **DEFENSE_MODE=on**(평소 운영값)인 포털에 돌리면: 1~3단계는 OK, 4단계는 보통 BLOCKED(게이트웨이가 기밀 문서 접근을 막음), 5단계는 토큰이 없어 자동으로 건너뜀 → **방어가 정상 동작한다는 증거**.
- **DEFENSE_MODE=off**(공방전 공격 성공 시연용, `scripts/leesh/7_AI채팅_실행_방어꺼짐_공격시연.cmd`로 띄운 포털)에 돌리면: 4단계에서 토큰·식별 문구가 새고, 5단계에서 FLAG까지 나올 수 있다 → **공격이 성공하는 장면**.

양쪽 다 돌려서 결과를 비교해 두면 발표·보고서에 "방어 켬/끔 비교"로 쓰기 좋다.

## 주의
- 반드시 **우리 포털**(`--base`)에만 쓴다. 다른 서버에 쓰지 않는다.
- 비밀번호를 명령줄에 그대로 넣으면 셸 기록에 남을 수 있다. 시연이 끝나면 README나 발표 자료에서 실제 비밀번호를 지운다.
